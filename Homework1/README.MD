# How to Run My Code

1. Run `source Homework_1_Env/bin/activate` to activate Homework1's venv.
2. Go into the src directory located in the Homework1 directory
3. Run `python task_#.py` to run the code.

# How to Run My tests

1. Follow step 1 in 'How to run my code' to activate the venv
2. Go into the Homework1 directory and run `python -m pytest -v` to run all the pytests for the tasks
